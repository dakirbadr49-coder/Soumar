# Site de Soumar

Site vitrine : présentation, œuvres et expositions.

En ligne : https://dakirbadr49-coder.github.io/Soumar/

## Modifier le site (admin)

1. Aller sur https://app.pagescms.org et se connecter avec son compte GitHub.
2. Ouvrir le dépôt **Soumar**.
3. Dans le menu : **Accueil et À propos**, **Œuvres**, **Expositions**, **Contact et réseaux**.
4. Modifier, puis cliquer sur **Save**. Le site est mis à jour en 1 à 2 minutes.

Conseil : avant d'envoyer une photo, la réduire à environ 1600 pixels de large
pour que le site reste rapide sur téléphone.

## Organisation

- `content/` : les textes, tableaux, expositions et contacts (modifiés par l'admin)
- `images/` : les photos
- `index.html`, `style.css`, `site.js` : la mise en page
- `.pages.yml` : la configuration de l'admin
